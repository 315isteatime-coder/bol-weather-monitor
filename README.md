# KIIKII 内部工具

珠海十字门 C1017 店内部用，手机优先。线上：**ieclong.com**

## 三个页
- **今日** 本月达成率、我的私佣公佣实收、本周挂单条形图、假期奖励进度
- **佣金** 填店铺营业额 + 我的挂单额 + 工时，即出私佣／公佣／大单奖／实收
- **排班** 一周视图，点名字排更，顺手填当日挂单额

## 规则真源
佣金规则来自 KIIKII repo `十字门C1017/开业筹备/珠海店-人员编制与薪酬提成方案-v1.md` §5（v6 定稿 2026-09-07）。
**改规则先改那份文件，再改 `app.js` 顶部常数。** 这里只是执行，不是真源。

摘要：
- 私佣 ＝ 当档费率（封顶 3%）× 个人目标以内 ＋ 6% × 超出部分
  个人目标 ＝ 月目标 ÷ 全职人数，兼职按工时折算
- 公佣 ＝ 当档费率（达标 4%）× 全店营业额，店长先分 20%，其余按上班时间摊分
- 大单奖 满 800／1400／2400 加 10／30／50，取最高档
- 全店达成 120% → 每人加一天带薪假
- 开业头三个月费率封顶 2%，6% 不开放

## 技术取舍
**零外部请求。** 用户在珠海，Google Fonts 被墙、unpkg／jsdelivr 不稳，
而本 repo 2026-07-11 那条 commit 已经证实 esm.sh 动态 import 会令手机提交失败。
所以：系统字体、无图示库、无 CDN、无框架。三个文件就是全部。

## 已知限制
- **数据只存在每部手机的 localStorage。** 排班不是全店共用的一份，店长排完员工手机不会自动看到。
  要共用得接后端（旧的 Supabase 项目 `pofaxxvjcdugqimummsr` 还在，可以加一张 `roster` 表）。
- 身分靠点右上角名字轮着切，没有登入。任何人开链接都看得到。
- 佣金页算的是估算，发薪以店长实际结算为准。

## 设计
半径三档：卡 24px ／ 输入 14px ／ 按钮同 chip 999px。
accent 只有 KIIKII 红 `#f60000`（大字同装饰）、`#c40000`（细字）、`#d10000`（做底）。
参考方向：健康追踪 app dashboard 的卡片语言。
